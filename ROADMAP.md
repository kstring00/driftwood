# Driftwood Roadmap

Driftwood is being built as vertical slices. Each stage should be playable before the next layer is added.

## Stage 0 — Survival Proof ✅
- Day/night cycle
- Resource gathering
- Barricades, campfires, wards
- Enemy waves
- Infection pressure
- Holy Warden and Arcane Mage combat

## Stage I — The Wanderer ✅
- Character name and appearance customization
- Chunkier gothic pixel character rendering
- Health + class-power potions
- Inventory and equipment screen
- Weapon / head / chest / boots / charm slots
- Common, Enchanted, Rare, and Relic loot
- Gear changes damage, armor, life, power, regeneration, and movement
- Enemy loot drops scale upward with later nights

## Stage II — The Survivor
- Crafting stations and recipes
- Food, water, shelter, temperature, and rest decisions
- Multiple diseases with symptoms, stages, and specific cures
- Gathering/crafting loop for medicine
- Storage chests and persistent camp upgrades
- Better structure placement and repair

## Stage III — The World
- True isometric tile map
- Hand-authored low-resolution gothic sprites and animation sets
- Coast, forest, marsh, ruins, caves, and abandoned settlement biomes
- Clickable/visible world loot
- Lighting, weather, fog, interiors, and dungeon entrances
- More enemy silhouettes and environmental storytelling

## Stage IV — The Build
- Full skill trees and specialization choices
- Holy, arcane, martial, ranger, and alchemy archetypes
- Named elites, bosses, affixes, resistances, and set/relic gear
- Quests, shrines, world events, and dungeon rewards
- Deeper item comparison and crafting/enchanting

## Stage V — Persistence & Endgame
- Save/load
- Character progression across runs
- World seed / map persistence
- Endgame night escalation and boss cycles
- Optional co-op exploration after the single-player game is stable
